# Unofficial Emotiva Remote

A remote control app for [Emotiva](https://emotiva.com/) XMC and RMC home
theater processors. It is written in [Dart](https://dart.dev) using
[Flutter](https://flutter.dev) and is published on the
[Google Play Store](https://play.google.com/store/apps/details?id=one.woodbury.emotiva_remote)
and the
[Apple App Store](https://apps.apple.com/us/app/unofficial-emotiva-remote/id6741597070).

## Compatibility

The XMC-2, RMC-1, and RMC-1L running firmware v3.2 is expected to work well.

As of 2026-11-7, the
[release notes](https://emotivalounge.proboards.com/thread/62344/update-version-rmc-xmc-firmware)
for the latest firmware (v5.7) continue to include, _"Emotiva Remote App may no
longer work (your results may vary)"_.

Some users have reported that this app continues to work on firmware v5.x when
using the _Manually connect_ feature.

Compatibility with the new LX processors is unlikely. Emotiva has released the
[Emotiva Emersa Control](https://play.google.com/store/apps/details?id=com.emotiva.emersa)
app for the LX processors.
